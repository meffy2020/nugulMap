# 흡연구역 원본 대조 감사 — 2026-09-07

**출시용 검증 완료 데이터가 아니다.** 기존 최종 CSV 1,061행을 보존한 채 원본과의 정확한 필드 대응 및 품질 문제를 기록했다. 실제 현장 확인·현재 흡연 허용 여부를 입증한 행은 0행이다. 파일명 날짜, 포털 수정일, 원본의 데이터기준일은 각각 기록하되 현장 확인일로 변환하지 않았다.

## 결과

| 항목 | 행 수 |
| --- | ---: |
| 최종 CSV | 1,061 |
| 원본 주소와 정확히 대응하는 행 | 1,058 |
| 주소 누락·무효 / 원본 주소 대응 없음 | 3 |
| 지역 필드 누락 | 849 |

최종 행에는 전 필드가 같은 중복 0행, 형식상 무효 좌표 0행, 넓은 대한민국 검토 범위를 벗어난 좌표 0행이 있다. 같은 좌표를 공유하는 그룹은 75개이며 삭제하지 않았다. 원본에서는 안양 2024 파일 2행, 영등포 파일 각 사본 1행이 넓은 검토 범위를 벗어나므로 원본 좌표 역시 그대로 신뢰할 수 없다.

숫자는 중복 집계다. 47개 원본 파일(중복 사본 포함), 1,706행을 조사했다. 통계표인 중랑구 `흡연정보`는 위치 대조에 사용하지 않았다. 151행 후보 중 101행도 파일명 날짜 기준 365일을 초과한다. **이 151행을 그대로 공개하거나 원본을 대체해서는 안 된다.**

최종 데이터는 전부 `type=실외`이나, 광진구·부산 서구 원본에 실내 시설이 있다. 실내 충돌 227행은 동일 주소의 다른 시설 가능성도 포함한 검토 신호이며, 모두 확정 오분류라고 단정하지 않는다. 좌표 차이 7행도 동일 주소의 여러 시설·출입구일 수 있다. 원본의 시설명과 행을 확인한 뒤 수정해야 한다.

빈 주소는 CSV 507·771행, 문자 `실외`를 주소로 둔 행은 752행이다. 숫자만 있는 주소는 이번 최종 CSV 검사에서 발견되지 않았다. 기존 요약에서 언급된 숫자 값은 최종 주소 오류로 재현되지 않아 여기서는 집계하지 않았다.

## 산출물

- `rows.json`: 최종 1,061행 전부와 대응 원본 파일 경로·CSV 행 번호·주소 열·좌표 비교·원본 기준일·문제 플래그. CSV 행 번호는 헤더를 1행으로 센다.
- `sources.json`: 원본별 SHA-256, 인코딩, 열, 행 수, 파일명 날짜, 공식 카탈로그 대응.
- `review-queue.csv`: 전 행 검토 목록. 플래그로 우선순위를 정한다.
- `coordinate-backed-review-only.csv`: 주소·좌표가 정확히 대응하고 무효 주소·좌표 차이·실내 충돌·정확한 중복이 없는 검토 후보. 지역 누락, 오래된 출처, 여러 원본 후보는 남을 수 있다.
- `summary.json`: 재현 가능한 집계와 최종 CSV SHA-256.
- `official-source-catalog.json`: 공식 공공데이터포털 제목이 일치한 38/44개 고유 파일명의 메타데이터. 나머지는 미해결 상태를 그대로 둔다.
- `jongno-current-dataset-metadata.json`: 기존 자료와 분리한 종로구 신규 출처 후보 메타데이터. 위치 데이터 다운로드·지오코딩·운영 DB 반영은 하지 않았다.

## 방법과 한계

문자열은 Unicode NFC와 연속 공백만 정규화했다. 주소 약칭 확장, 띄어쓰기 제거, 유사도, 가까운 좌표로 출처를 추정하지 않았다. 좌표는 Decimal로 정확히 비교한다. 좌표 공유만으로 중복 삭제하지 않으며 층별·시설별 행을 유지한다. 전 필드가 같은 행만 정확한 중복으로 표시한다. 좌표 검사 범위는 전 지구 유효 범위 및 대한민국 주변의 넓은 검토 범위(위도 33–39.5, 경도 124–132)다. 행정구역·건물·출입구의 실제 위치 검증은 아니다.

주소 일치는 **원본 행과의 대응 근거**이며 실제 변환·수입 계보의 증명은 아니다. 중복 사본과 다른 연도 자료를 모두 기록하고 최신 파일을 실제 출처로 임의 지정하지 않았다. 원본에 좌표가 없는 900행 등의 좌표가 어떤 지오코더·검색 결과에서 왔는지 복원할 근거가 없다. 기존 `upload_to_mysql.py`는 열 이름을 추정해 주소 등을 매핑하고 출처 ID·해시·확인일을 보존하지 않는다. `final_zones_all.csv`를 만든 스크립트는 저장소 검색에서 찾지 못했다. 이 감사는 그 수입 스크립트를 실행하지 않는다.

365일은 이번 검토의 고정 경고 기준일 뿐 법적 유효기간이나 폐쇄 판정이 아니다. 대응 원본이 최근이어도 개별 장소가 현장에서 확인됐다는 의미는 아니다. 포털 URL 대응은 제목 기준이며 로컬 파일 내용이 현재 다운로드와 동일하다고 검증한 결과가 아니다.

## 재현

저장소 루트에서 Python 표준 라이브러리만 사용한다. 감사는 기본적으로 오프라인이다.

```sh
python3 -m unittest discover -s backend/data-scripts/scripts -p test_audit_smoking_sources.py -v
python3 backend/data-scripts/scripts/audit_smoking_sources.py --output-dir docs/data-audit --as-of 2026-09-07 --catalog docs/data-audit/official-source-catalog.json
```

공식 메타데이터를 새로 확인할 때만 다음 읽기 전용 네트워크 명령을 사용한다. 포털 변경으로 일부 제목이 미해결될 수 있고, 새 결과는 검토해야 한다.

```sh
python3 backend/data-scripts/scripts/resolve_smoking_source_catalog.py --data-dir backend/data-scripts/data --output-dir docs/data-audit --checked-on 2026-09-07
```

원본 CSV, 최종 CSV, 운영 DB는 변경하지 않았다.

검증: 표준 라이브러리 회귀 테스트 3개 통과, Python 컴파일 검사 통과, 동일 입력으로 행별 결과를 재생성해 바이트 일치 확인. 거리 기반 추정 배제·실내 충돌·복수 원본·동일 좌표의 층별 보존·무효 값·공식 제목 대응을 검사한다.
